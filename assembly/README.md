# Assembly Programs

Contains assembly source files for the 8-bit breadboard computer:
* `fibonacci.asm`: Fibonacci sequence generator[cite: 1]
* `multiply.asm`: Iterative multiplication routine[cite: 1]
* `square_numbers.asm`: Odd-sum method integer squaring[cite: 1]
* `triangular_numbers.asm`: Iterative triangular number summation[cite: 1]
